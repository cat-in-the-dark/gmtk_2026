# DUCKsumo

A 3D toy game where you can slap enemies out of the platform like in sumo.

Made in solo in 2 days for GMTK-2026. Rate my game here: https://itch.io/jam/gmtk-jam-2026/rate/4828755.

![](./assets/screenshot1.png)

Gameplay video: https://www.youtube.com/watch?v=wsobLPplSrg

## Controls

- **Movement**: WASD or Arrows or D-pad
- **Attack**: Space or Gamepad A
- **Dash**: Shift or Gamepad B

## Credits 

- All models, textures and animations were created in blockbench.
- Gdscript code was written with codex.
